# 📊 Netflix Titles Exploratory Analysis

Exploratory data analysis of the Netflix Titles dataset using Python, Pandas, Matplotlib, and Seaborn. The project examines how Netflix’s catalog has evolved over time through trends in content type, country production, monthly additions, and movie duration patterns.

---

## 🔧 Tools & Libraries
- Python  
- Pandas, NumPy  
- Matplotlib, Seaborn  

---

## 🧹 Data Preparation
- Cleaned and standardized 8,000+ records using Pandas  
- Handled missing values and normalized categorical fields  
- Extracted month/year from `date_added`  
- Parsed multi‑genre fields and created duration‑based features  

---

## 🔍 Key Questions Explored
- How has the ratio of Movies vs. TV Shows changed over time  
- Which countries produce the most Netflix content  
- Are there seasonal patterns in titles added by month  
- How average movie duration has changed across release years  

---

## 📈 Visual Insights
Visualizations highlight:
- Shifts in catalog composition  
- Global content production patterns  
- Monthly release cycles  
- Long‑term duration trends
